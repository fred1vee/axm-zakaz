# Учёт заказов — PWA

Залейте всю папку на хостинг **по HTTPS** (Netlify, Vercel, GitHub Pages, свой сервер). Работает и в подпапке.
Локально: `python3 -m http.server` → http://localhost:8000

- Данные хранятся на устройстве (localStorage). Экспорт и импорт файла данных: блок «Сохранение данных» внизу экрана.
- Обновления: index.html всегда берётся из сети; когда вы меняете sw.js, у пользователей появится кнопка «Update».
- При смене иконок/манифеста поднимите `V` в sw.js (uz-v1 → uz-v2).
- Язык баннера установки: константа `LANG` в конце index.html ('en' или 'ru').
- Сервер не должен долго кэшировать sw.js (Cache-Control: no-cache).
